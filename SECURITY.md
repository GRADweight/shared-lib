# Sicherheit

Bitte melde Schwachstellen nicht über öffentliche Issues, sondern vertraulich:

- über GitHub «Report a vulnerability» (Private Vulnerability Reporting) in diesem Repository, oder
- per E-Mail an mail@gradweight.ch

Wir bestätigen den Eingang innerhalb von fünf Arbeitstagen. Dieses Paket ist im
Wartungsmodus; Sicherheitskorrekturen werden weiterhin bereitgestellt.
